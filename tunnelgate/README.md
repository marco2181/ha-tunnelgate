# TunnelGate

![aarch64][aarch64-badge] ![amd64][amd64-badge]

Route only selected devices (TV, streaming stick, console…) through a WireGuard VPN tunnel of your NordVPN subscription — with kill switch, DNS leak protection, a sidebar panel and MQTT entities.

Unofficial, not affiliated with Nord Security / NordVPN. See the **Documentation** tab.
